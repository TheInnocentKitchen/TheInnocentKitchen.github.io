Local data & backup

Orders and recipes are stored in this browser on this device. No account or server is required for normal use. Clearing browser data or uninstalling the browser can erase local data, so export backups regularly.

Offline note: after the app has been served once from an HTTPS address and installed/opened, its files can be cached for offline use. Opening index.html directly from a file manager supports local calculations but does not enable full PWA installation/service-worker caching.

How to install on Android

  1. Upload the included app files to an HTTPS static host.
  2. Open the hosted address in Chrome while online.
  3. Choose Install app or Add to Home screen from the browser menu.
  4. Open the installed app once; after caching, order entry and aggregation work offline.
